# 2단계 — 4지선다 기출원문 모의고사(PDF) 가져오기

사용자가 올린 PDF 2종(문제편 14쪽 / 정답 및 해설편 43쪽, 이윤탁 형사소송법 기출원문 모의고사 제1회)은
OX 문제집이 아니라 **4지선다**였다. 사용자 결정(A안)에 따라 4지선다를 그대로 보관하고,
해설편의 선지별 ○× 표시에서 **OX 변형 문항(파생)**을 별도 생성한다. 원본 PDF는 저작권 자료이므로 저장소에 넣지 않았다.

## 구조
- `tools/mcq_import/mcq_pdf_import.py` (poppler `pdftotext` 필요)
  - 2단 편집을 단별로 잘라 읽음 (문제편: 좌→우 / 해설편: 왼쪽=문제 재수록, 오른쪽=○×·근거·정답).
  - 문제편과 해설편의 문제 재수록을 서로 대조.
  - 정답은 ① 정답 모아보기 표 ② 해설 말미 '정답 N' 을 교차 확인. 불일치 시 경고.
  - **정답 선지와 항목별 원본 ○× 가 맞아떨어질 때만(`verdict_ok`) OX 변환**. 원본이 모순되거나 표시가 깨졌으면 변환 제외 + 경고. 정답을 고치지 않는다.
  - 출력: `questions.jsonl`, `report.json`, `seed.sql`(모두 pending). `--version-no 2` 로 재가져오기(PDF→HWPX) 시 신원은 유지하고 새 버전만 추가.
- DB(`001_game_schema.sql`): `question_type`(ox/mcq), `derived_from_question_id`, 버전의 `choices/bogi/stem_note`.
  학생용 뷰(`game_playable_questions`)는 선지·보기 텍스트만 노출하고 ○×/해설은 숨김. 채점 함수가 유형별로 O/X 또는 1~4 를 검증.
  (001 은 아직 어떤 DB 에도 적용된 적이 없어 직접 수정했다.)

## 실제 PDF 변환 결과 (제1회)
| 항목 | 값 |
|---|---|
| 4지선다 문항 | 52 (정답 모아보기 표에는 1~30번만 있음, 31~52번은 해설의 '정답' 표시로만 확인) |
| 정답 교차확인 | 표가 있는 30문항 모두 해설 정답과 일치 |
| 원본 ○× 와 정답이 일관된 문항(`verdict_ok`) | 44 |
| 파생 OX 후보 | 176 (O 114 / X 62) — 전부 pending, 검수 전 출제 불가 |
| 검수 필요 문항 | 8건 (아래) — 나머지 44문항은 정답과 ○× 표시가 서로 일치 |

검수 필요 목록 (총 8건: 2, 6, 23, 25, 29, 31, 32, 39)
- 원본 자체가 모순으로 보이는 문항 — 육안 확인함: **25번**(해설 첫 줄은 'ㄴ, ㄹ이 옳다', 정답 ③도 ㄴ,ㄹ인데 항목별 표시는 ㉠○ ㉡○ ㉢× ㉣×),
  **29번**(해설 첫 줄은 '㉠, ㉣이 옳다'인데 정답 모아보기와 해설 정답이 모두 ①(㉠㉡)). 원본을 직접 확인해 주세요.
- 파서가 모순으로 판정했으나 육안 미확인: 23번, 31번
- PDF 텍스트 손상으로 ○× 누락: 6번(②), 32번(㉡), 39번(③)
- 선지가 명사구라 ○× 검증 불가: 2번
- 위 문항의 정답은 **원본 값 그대로** 보존했고 AI가 고치지 않았다. 이 8문항에서는 OX 변형 문항을 만들지 않았다.

## 알려진 한계
- PDF 줄바꿈은 글자 단위라 줄 끝의 띄어쓰기 유무가 소실된다. 문제편과 해설편에 같은 지문이 재수록되어 있어 대조로 복원을 시도했으나,
  **두 PDF의 줄바꿈 위치가 동일해 복원 가능한 자리가 0건**이었다(실측). 따라서 모든 줄바꿈 자리는 붙여쓰기로 처리했고
  (문제 본문 약 640곳, 해설 본문 약 1,090곳), 문항별 `wrap_ambiguous` 에 기록한다. 검증 근거가 없는 추측 규칙으로 글자를 바꾸지는 않았다.
  화면에서 "인식이있음을"처럼 붙어 보이는 곳이 있다. **HWPX 원본 수령 후 재변환(`--version-no 2`)이 근본 해결책.**
- 단원은 '제1회 총론·수사의 개시·임의수사' 한 덩어리로만 분류됨. 세부 단원 분류는 미구현.
- 난이도/중요도/출제빈도는 비워 둠(출제빈도는 '미확인').
- 한자 부수 변형 글자(예: ⼄)는 통상 한자(乙)로 치환.
- HWPX 입력용 4지선다 파서는 아직 없음(현재 HWPX 는 OX 형식 파서만).

# HWPX 판 (제1·2회 문제편/해설편) — PDF 판을 대체

`tools/mcq_import/mcq_hwpx_import.py` — 검수 기준·파생 OX·SQL 은 PDF 판과 공유, 읽기만 HWPX.
```
python3 tools/mcq_import/mcq_hwpx_import.py --exam 문제1.hwpx 해설1.hwpx --exam 문제2.hwpx 해설2.hwpx --out OUT/
python3 tools/export_game_json.py OUT/questions.jsonl --out public/game-data/questions.local.json
```
- 줄바꿈 띄어쓰기 소실·2단 편집 문제 해소(문단 단위 추출). 문제편/해설편은 내용으로 자동 판별.
- 정답 모아보기 표의 두 형식(번호·정답 쌍 / 번호 행 → 정답 행) 모두 지원, 회차·범위는 해설편 머리말에서 읽음.
- **버그 수정**: `<hp:t>① 가<hp:tab/>② 나</hp:t>` 에서 탭 뒤 글자가 버려지던 읽기 버그(OX 읽기 도구 포함) → 회귀 테스트 추가.
- 게임 내보내기(`export_game_json.py`)는 **검증 통과 문항만** 포함: 4지선다 100 + 파생 OX 401 = 501문항. 경고 있는 14문항 제외.

| 회차 | 범위 | 4지선다 | 정답표↔해설 정답 | 검증 통과 | 제외 |
|---|---|---|---|---|---|
| 제1회 | 총론·수사의 개시·임의수사 | 52 | 표 30개 모두 일치 (31~52번은 표에 없음) | 44 | 8 |
| 제2회 | 대인적 강제수사·대물적 강제수사(1) | 62 | 62개 모두 일치 | 56 | 6 |

## 제외된 문항 = **원본 파일 자체의 문제** (HWPX 에서도 동일, 파서/PDF 오류 아님)
- 제1회: 6번(`① ○ ②헌재…`처럼 ② 표시가 앞 문단에 붙음), 32번(㉡ 항목 해설 누락), 39번(`② × ③형법…` ③ 표시 붙음),
  25번·29번(해설 첫 줄의 '옳은 지문'과 항목별 ○×·정답 불일치), 23번·31번(표시 불일치), 2번(선지가 명사구)
- 제2회: 3번·60번(발문 유형 불명), 17번(계산형, 선지별 해설 없음), 45번(**문제편은 '옳지 않은 것', 해설편 재수록은 '옳은 것'으로 서로 다른 문제**),
  55번(④ ○× 없음, `① ○ , ②대판…`), 59번(④ ○× 없음)
- 정답은 원본 값 그대로 보존, AI가 고치지 않음. 최종 원고 수정 후 `--version-no 2` 로 재가져오면 기존 학습기록을 유지한 채 새 버전으로 교체된다.

## 확정된 사항: OX 문제집의 Ⓐ/Ⓑ/Ⓒ (사용자 확인)
- Ⓐ/Ⓑ/Ⓒ 는 **반복빈도 표시**다. 원문 그대로 `raw_markers` 에 보존하고 뜻은 `반복빈도 등급(저자 표시)`로만 기록한다.
- **게임 출제·난이도·보상에는 반영하지 않는다**(사용자 결정).
- 저자 표시일 뿐 검증된 기출 횟수가 아니므로 `exam_frequency`(출제빈도 숫자)는 계속 '미확인'. 등급 순서(Ⓐ가 높은지)는 확인받지 않아 기록하지 않았다.
