# 움직이는 그림(프레임) 제작 규격

지금 게임은 그림 한 장을 코드로 변형해서 움직임을 만든다. 사람이 그린 프레임이 있으면 훨씬 자연스럽다. 아래 규격으로 만들면 연결해 준다.

## 공통
- 투명 PNG, 같은 캔버스 크기(프레임마다 발 위치·크기가 같아야 함), 헌터는 오른쪽·악당은 왼쪽을 향함
- 파일명: `<대상>-<동작>-<번호>.png` (예: `male-run-1.png`)
- 각 동작은 반복 가능(마지막 프레임 → 첫 프레임이 자연스럽게 이어짐)

## 헌터 (남/여 × 입문·정예·전설 = 6벌)
| 동작 | 프레임 | 설명 |
|---|---|---|
| idle | 2~4 | 숨쉬기 |
| run | 6~8 | 달리기(팔·다리·몸이 모두 움직임) |
| charge | 2 | 대치: 웅크리고 기 모으는 자세 |
| attack | 4 | 뒤로 당김 → 휘두름 → 임팩트 → 복귀 |
| hurt | 2~3 | 맞고 뒤로 젖혀짐 |

## 악당 (일반 5종 + 보스 6종)
| 동작 | 프레임 | 설명 |
|---|---|---|
| idle | 4 | 움직이는 대기 |
| charge | 2 | 공격 전 기 모으기 |
| attack | 3~4 | 덮치는 동작 |
| hit | 2 | 맞고 움찔 |
| die | 3 | 쓰러짐 |

현재 변형(코드)으로 이미 구현된 동작: 달리기, 공격, 피격, 대치, 쓰러짐. 프레임이 오면 같은 시간표(`src/game/anim.ts`)에 맞춰 프레임 번호만 바꿔 끼운다.
