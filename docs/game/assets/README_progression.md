# 노량진 형사법 헌터 성장 이미지 팩

`public/hunter-assets/progression/`을 기존 게임의 정적 파일 경로에 복사하세요. `progression-manifest.json`에는 개별 이미지 경로, 정규화된 좌표, 5단계 성장 배치 예시가 들어 있습니다. 1단계는 기존 이미지 팩과 전투 이미지 팩의 경로를 사용합니다.

| 진행 단계 예시 | 해금 펫 | 무기 | 보스 |
| --- | --- | --- | --- |
| 1 입문 | 법전 토끼, 책가방 시바 | 각인 기본봉 | 잉크 보스 |
| 2 수련 | 판례 부엉이, 증거 여우 | 푸른 수정검 | 철쇄 간수장 |
| 3 정예 | 철갑 거북, 별빛 까마귀 | 판결 망치 | 붉은 잉크 악마 |
| 4 달인 | 청염 아기용 | 청룡 언월도 | 용암룡 |
| 5 전설 | 황금 해치 | 황금 정의대검 | 심연 괴수 → 흑요석 용왕 → 용왕 폭주 |

위 표는 배치 예시입니다. 실제 해금 조건과 체력은 게임의 레벨·단원 진행 로직에서 정하세요. 용왕 폭주는 같은 최종 보스의 두 번째 형태로 쓰면 됩니다.

## 화면에 배치하기

- 펫은 소유 목록에서 선택한 한 마리를 헌터 뒤에 표시하는 구성을 기준으로 했습니다. `floatY`가 있는 펫은 화면 높이에 해당 값을 곱해 그만큼 위로 띄울 수 있습니다.
- 정예·전설 헌터의 공격 베이스는 손이 비어 있습니다. 선택한 무기의 `grip`이 캐릭터의 `handGrip`과 같은 화면 좌표에 오도록 무기를 그리세요. 그 위에 헌터를 그리면 주먹이 손잡이를 자연스럽게 가립니다. `grip`과 `handGrip`은 이미지 자체 크기에 대한 0~1 좌표입니다.
- 예를 들어 캐릭터를 그리는 사각형의 왼쪽 위가 `(hx, hy)`, 크기가 `(hw, hh)`라면 손 위치는 `(hx + hw * handGrip.x, hy + hh * handGrip.y)`입니다. 무기 왼쪽 위는 이 위치에서 `(무기 표시 폭 * grip.x, 무기 표시 높이 * grip.y)`를 빼면 됩니다. 무기 표시 폭은 헌터 표시 높이에 `widthInHunterHeights`를 곱한 값부터 맞춰 보세요.
- 공격 베이스와 각인 무기는 오른쪽을 향합니다. 장비창에서는 무기의 각인이 읽히는 정방향으로 표시하세요.
- 보스는 왼쪽을 향하고, `anchor`는 바닥 배치 기준점입니다. 기존 배경과 보스 전용 배경 모두 화면 높이에 `groundY`를 곱해 바닥 위치를 계산합니다.

게임에 붙이기 위한 이미지와 좌표를 제공하는 팩입니다. 펫 추종, 무기 교체, 보스 변신은 게임 이벤트에서 이미지를 바꿔 연결하세요.
