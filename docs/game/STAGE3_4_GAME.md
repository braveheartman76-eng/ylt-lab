# 3·4단계 — 학습 엔진 + 플레이 가능한 게임 화면 (로컬 모드 1차)

접속: `/game` (개발 서버 `npm run dev` 후). 기존 사이트 레이아웃은 수정하지 않고 게임만 전체 화면으로 덮는다.

## 구성
| 위치 | 역할 |
|---|---|
| `src/game/engine/srs.ts` | 복습 일정·보상·레벨 (DB `game_submit_attempt` 와 동일 규칙) |
| `src/game/engine/picker.ts` | 출제 혼합(복습 40 / 새 문제 35 / 과거 오답 10 / 도전 15) + 최근 정답률 기반 목표 난이도 |
| `src/game/engine/stats.ts` | 단원별 정답률·복습 정답률·취약 단원 추천(근거 5회 미만이면 추천 안 함) |
| `src/game/tts.ts` | 브라우저 Web Speech API(켜기/끄기, 속도, 첫 터치로 잠금 해제) — 독립 모듈 |
| `src/game/store.ts` | localStorage 저장(풀이 기록 append-only) |
| `src/game/world.ts` | 스테이지 배경 6종, 아이템 15종(DB 시드와 id 동일), 공부방 단계 |
| `src/components/game/RunnerCanvas.tsx` | 자동 달리기·점프·장애물·코인·공격/반격 연출(임시 도안) |
| `src/components/game/GameClient.tsx` | 문제 출제·자동 진행·피드백·복습/리포트/내 방 탭 |
| `tools/export_game_json.py` | 변환 결과 → `public/game-data/questions.local.json` (gitignore) |

## 동작 규칙
- 달리다 문제 앞에서 멈춤 → OX/4지선다 출제 → 정답: 몬스터에 공격 + XP/코인, 오답: 몬스터 반격 + 정답/해설 + 복습 예약 → 자동으로 다음 구간(정답 3.2초, 오답 6.5초, 버튼으로 즉시 진행).
- 스테이지당 정답 5번이면 몬스터 처치 → 아이템 지급, 다음 스테이지(배경 변경). 5·10… 스테이지는 보스 외형. 오답 3번이면 체력만 회복(게임오버 없음, 오답은 모두 기록).
- 보상은 '처음 푸는 문항 / 복습 예정 문항' 정답에만 지급 → 쉬운 문제 반복 파밍 방지. 경험치(레벨)는 학습 숙련도와 별개.
- 데이터: `questions.local.json`(있으면) → 없으면 `questions.sample.json`(가상 테스트 9문항).

## 검증 결과
- 엔진 단위 테스트 8건, **TS 엔진 ↔ SQL 함수 동등성** 무작위 200회 대조 통과(규칙을 일부러 틀리게 바꾸면 12번째 풀이에서 실패함을 확인).
- `tsc --noEmit` 통과, 게임 관련 파일 ESLint 통과(사이트 기존 파일의 lint 오류 9건은 기존 것).
- Playwright(모바일 390×844)로 실제 플레이: 시작 → 문제 6개(OX/4지선다) 풀이 → 저장 → 새로고침 후 기록 유지 → 복습/리포트/내 방 탭, 콘솔 오류 없음.

## 아직 안 된 것 / 한계
- **로컬 모드**: 정답이 브라우저에 있고 기록은 기기(localStorage)에만 저장. 로그인·Supabase 연동(RPC 채점, RLS) 미연결 — 개발용 Supabase 승인/접속 정보 필요.
- 캐릭터·몬스터·배경은 도형으로 그린 **임시 도안**. 걷기/달리기/점프/공격은 있으나 외형 변화·직렬별 의상·아이템 장착 표시는 없음(캐릭터 별도 제작 예정).
- 사건 수사 미션, 조문 보스전(단원 HP), 주간 평가(S~D 등급), 관리자 검수 화면, 상점(코인 사용) 미구현.
- 소리(효과음/BGM) 없음. TTS는 브라우저 지원·한국어 음성 설치에 의존, 실제 음성 출력은 이 환경에서 확인 못 함(코드 경로만 구현).
- 문제 본문에 PDF 유래 띄어쓰기 누락이 있음(2단계 문서 참고). 변환 문항은 검수 전.

## 변경(사용자 피드백 반영)
- **점프**: 화면 아무 곳이나 터치하면 점프(버튼·링크·탭 영역 제외, 스페이스바도 지원). 자동 점프 안 씀.
- **장애물 타이밍**: 달리는 속도를 낮추고(120px/s) 달리는 시간을 3.8초로 늘림. 첫 장애물은 달리기 시작 1초 뒤에 화면에 들어오고 닿기까지 약 2.3초 여유(실측: 1.1초에 등장).
- **미처리 오답 = 불시 공격/크리티컬**: 틀린 문제는 **같은 문제를 연속 2번 맞힐 때까지** 복습 시각과 무관하게 접속할 때마다 나온다.
  접속 직후 처음 3문제는 미처리 오답을 먼저 출제, 이후에도 약 35% 비율로 섞어 출제. 붉은 테두리 + "⚠ 불시 공격!" 연출, 맞히면 **크리티컬(몬스터 피해 2배)**.
  처리 전 다시 틀리면 연속 정답이 0부터 다시 시작(오답 누적 기록은 유지). 보상(XP/코인) 규칙은 기존 SRS 그대로(파밍 방지).
- 복습 탭 → "오답 복습(크리티컬 공격)": 미처리 오답 목록과 "처리까지 연속 정답 n/2".
- 모바일 레이아웃: 게임(/game)에서는 사이트 공통 헤더/사이드바를 그리지 않음(`src/components/SiteChrome.tsx`, `layout.tsx` 에서 사용). 기존에는 사이트 틀이 폭 390px보다 넓어 모바일에서 오른쪽이 잘렸다.
- 이미지/사운드는 이후 단계: 그림은 `RunnerCanvas.tsx` 의 drawPlayer/drawMonster/배경 함수, 소리는 새 모듈 추가로 교체·확장 가능.

- 로더 `src/game/assets.ts`: 하나라도 불러오지 못하면 `null` → 기존 도형 그림으로 자동 대체(게임은 계속 동작).

  현재는 문제가 섞여 출제되고 소제목이 바뀔 때마다 문이 나온다.

## 성장 시스템(펫·무기·보스) + 효과음 (사용자 제작 성장 팩 적용)
- 그림: `public/hunter-assets/progression/` (펫 8·무기 4·보스 6·정예/전설 헌터 8·보스 배경 2). 설명서는 `docs/game/assets/README_progression.md`.
  성장 팩 이미지는 **필요할 때만 불러온다**(약 7MB를 한 번에 받지 않음). 불러오기 전/실패 시 기본 헌터·기본 보스로 대체.
- **성장 단계**(`world.ts` TIERS): 입문 → 수련(Lv.3) → 정예(Lv.6) → 달인(Lv.10) → 전설(Lv.15). 단계는 **게임 레벨**로 정한다. 레벨은 학습 보상(처음 푸는 문제/복습 문제 정답)으로만 오르므로 반복 파밍으로 올릴 수 없다.
  (레벨 필요 경험치: Lv.3=113, Lv.6=415, Lv.10=1311, Lv.15=4432 XP)
  | 단계 | 헌터 | 무기 | 해금 펫 | 보스(스테이지 5·10…) | 보스 배경 |
  |---|---|---|---|---|---|
  | 1 입문 | 기본 | 각인 기본봉 | 법전 토끼, 책가방 시바 | 잉크 보스 | 일반 |
  | 2 수련 | 정예 | 푸른 수정검 | 판례 부엉이, 증거 여우 | 철쇄 간수장 | 학원가 골목 |
  | 3 정예 | 정예 | 판결 망치 | 철갑 거북, 별빛 까마귀 | 붉은 잉크 악마 | 야간 자습실 |
  | 4 달인 | 전설 | 청룡 언월도 | 청염 아기용 | 용암룡 | 용암 동굴 |
  | 5 전설 | 전설 | 황금 정의대검 | 황금 해치 | 심연 괴수 ↔ 흑요석 용왕(체력 절반 이하에서 폭주 형태) | 심연의 왕좌 |
- 무기는 manifest 의 `grip`/`handGrip` 좌표에 맞춰 손에 쥐게 그리고(무기 → 헌터 순으로 겹침), 공격 시 손잡이를 축으로 휘두른다.
  정예/전설 헌터는 달리기 그림이 없어 대기 그림을 살짝 앞으로 기울이고 위아래로 흔들어 달리는 모습을 낸다.
- 펫은 해금된 것 중 하나를 골라 헌터 뒤를 따라다닌다(`내 방` 탭에서 선택, 저장). 헌터(남/여)도 `내 방` 탭에서 바꿀 수 있다.
- 보스 스테이지는 체력 8(일반 5), 처치 시 보너스 코인 +30. 단계 상승/레벨 업 시 안내 문구 + 효과음.
- **효과음 11종**(`src/game/sfx.ts`): 정답, 오답, 크리티컬, 베기, 점프, 부딪힘, 코인, 문 통과, 불시 공격 경고, 스테이지 클리어, 레벨 업.
  파일 없이 WebAudio 로 직접 합성(저작권·용량 문제 없음). 모바일은 '공부 시작' 터치에서 오디오 잠금 해제. 효과음 켜기/끄기·볼륨 저장.
- 테스트: `tests/engine/progression.test.mjs`(규칙 + manifest 일치 + 파일 존재), `tests/engine/sfx.test.mjs`(가짜 오디오 장치로 재생·무음·볼륨 검사).
  실제 브라우저(Playwright)에서 5단계 모두 캡처해 확인, 오디오 컨텍스트 `running` 및 소리 재료 생성 확인.
