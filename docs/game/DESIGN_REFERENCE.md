# 디자인 참고 메모 (사용자 제공 스크린샷 7장 기준)

참고 앱: HABIT FANTASY (습관 관리 앱). **참고용이며 이미지·캐릭터·도안은 저장소에 넣지 않고, 게임 리소스는 모두 독창적으로 새로 제작한다.**

## 우리가 가져올 "연출 방식" (아이디어만)
| 참고 화면 | 노량진 형사법 헌터에 적용 |
|---|---|
| 정답/습관 완료 시 캐릭터가 검을 휘둘러 몬스터 HP 감소, "경험치 +1" 표시 | OX 정답 = 공격 연출 + 경험치/코인 숫자 팝업 |
| BAD 누르면 몬스터 반격 | 오답 = 보스 반격 + 해설 표시 + 오답 기록 |
| 위쪽 전투 장면 + 아래쪽 흰색 카드 목록 (한 화면 2분할) | 위: 게임 장면, 아래: 오늘의 학습 미션/문제 카드 |
| 레벨(Lv), 경험치 바, "오늘의 과제 10/14" | 레벨 + 경험치 바 + "오늘의 복습 N/M" |
| 스테이지 번호(STAGE 21, 64)와 배경 테마 변화(숲→사막) | 노량진역→고시원→학원→독서실… 구간별 배경 |
| 주간 보스(남은 시간 카운트다운, 큰 HP) | 주간 평가 보스 / 단원 종합 보스 |
| 요일별 체크(✓/✗) 주간 표, 월간 달력 추적 | 학습 출석·주간 리포트 달력 |
| 난이도 표시(보통), 보상 코인 표시 | 문항 난이도 D1~D5, 보상은 학습 성과 연동 |
| 장비 도감(무기·방어구·모자·옷·바지·얼굴 탭, 별 등급) | 책가방·필기구·의상 슬롯 + 등급 |
| 레벨별 외형 변화(LV.1 → LV.20 → LV.99) | 학습 성과에 따른 수험생 외형 변화 |
| 펫 농장, 장착(Equipped) | (후순위) 동반 캐릭터/펫 |

## 주의할 점
- 참고 앱은 "습관을 지키면 보상" 구조다. 우리 게임은 **보상을 학습 성과(처음 푸는 문제/복습 예정 문제 정답)에 묶어** 쉬운 문제 반복 파밍을 막는다 (DB 규칙 이미 구현).
- 법 문제 화면은 읽기 쉬워야 하므로 전투 연출이 문제 본문을 가리지 않게 한다. 모바일 세로 화면 우선.
- 캐릭터 도안: 별도 제작 예정(사용자 확인). 참고 앱의 캐릭터·몬스터·펫·장비 그림은 모방하지 않는다.
