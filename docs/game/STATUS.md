## 데이터 저장 방식 (중요)
지금은 **각자 브라우저(localStorage)** 에만 저장된다. 기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라지고, 선생님이 학생 기록을 한곳에서 볼 수 없다.
서버 저장으로 옮기면 `supabase/game/001_game_schema.sql` (풀이 기록 append-only, 복습 일정, RLS, 서버 채점 RPC)을 그대로 쓴다.

## 서버 연결에 필요한 것 (승인/정보)
1. 개발용 Supabase 프로젝트(운영 DB와 분리) 사용 승인과 접속 정보(환경변수로만 사용)
2. 학생 가입 방식(이메일/카카오 등)과 선생님 계정 구분
3. 검수 담당자와 승인 절차(AI가 정답을 수정해 자동 배포하지 않음)
