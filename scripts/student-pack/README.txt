노량진 형사법 헌터 — 학생 테스트 버전
==========================================

이 폴더에는 게임이 들어 있습니다. 설치할 프로그램은 없습니다.
[site] 폴더가 게임 본체이고, 나머지는 실행을 도와주는 파일입니다.

■ 방법 A. 인터넷에 올려서 "링크"로 나눠 주기  (추천 — 학생 폰으로 바로 열려요)
  [site] 폴더를 정적 웹호스팅에 올리면 링크가 생깁니다. 링크를 학생들에게 보내 주세요.
  - Netlify Drop (https://app.netlify.com/drop): [site] 폴더를 끌어다 놓기
  - Vercel / Cloudflare Pages / GitHub Pages 등 어디든 가능
  ※ 반드시 "사이트 맨 위 주소"(예: https://이름.netlify.app/)에서 열려야 해요. 하위 폴더 주소(…/abc/)는 안 됩니다.
  ※ 올린 곳을 아는 사람은 누구나 열 수 있고, 문제와 정답이 파일에 들어 있어요. 공개 범위에 주의하세요.

■ 방법 B. 내 컴퓨터(Windows)에서 실행
  "start-windows.bat"을 더블클릭 → 브라우저가 열립니다. 끝낼 때는 검은 창을 닫으세요.
  (파란 경고창이 뜨면 "추가 정보 → 실행"을 누르세요.)

■ 방법 C. 내 컴퓨터(Mac)에서 실행
  "start-mac.command"를 더블클릭. 처음에는 터미널에서 chmod +x start-mac.command 가 필요할 수 있어요.
  (Python3 가 설치되어 있어야 합니다.)

------------------------------------------
학생에게 보낼 안내문 (복사해서 쓰세요)
------------------------------------------
[노량진 형사법 헌터 테스트]
1) 링크를 폰/PC 브라우저(크롬 권장)에서 여세요: (여기에 링크)
2) "진행 방식"을 고르고(한 문제씩 / 한 파트씩 자동진행) "공부 시작"을 누르세요.
3) 10~15분 이상 플레이해 보세요. 일부러 틀려도 보세요.
4) 끝나면 맨 아래 탭 "내 방" → "테스트 결과 복사하기"를 눌러 복사한 내용을 저에게 붙여넣어 보내 주세요.
5) 불편했던 점을 한두 줄로 적어 주세요. (아래 질문 참고)

[의견 질문]
- 어디가 가장 재미있었나요? / 가장 불편했나요?
- 문제·해설을 읽기 쉬웠나요? (글자 크기, 줄바꿈)
- 한 문제씩 / 한 파트씩 중 어느 쪽이 좋았나요? 왜요?
- 소리(효과음)는 어땠나요? 너무 크거나 거슬린 소리가 있었나요?
- 틀린 문제 복습(오답 탭, 불시 공격)은 도움이 됐나요?
- 오류가 났다면 어떤 화면에서 어떻게 했을 때인지 적어 주세요. (캡처하면 더 좋아요)

참고
- 기록(푼 문제, 레벨 등)은 각자 브라우저에 저장돼요. 다른 기기나 다른 브라우저에서는 처음부터 시작합니다.
- 시크릿(프라이빗) 모드에서는 기록이 저장되지 않아요.
- 효과음이 안 들리면 폰의 무음 모드와 볼륨을 확인하고, 화면 아래 "효과음" 체크를 확인하세요.
